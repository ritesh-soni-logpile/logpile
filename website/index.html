Curator FAQ

Architecture & Specifications

Everything you need to know about privacy, DRM, disk footprint, and data portability.

Unlike typical Windows applications that quietly dump gigabytes into your C:\Users\<user>\AppData partition, Logpile uses a strictly self-contained portable structure. All SQLite databases, artwork caches, and user preferences live in a folder named logpile_data right alongside the executable. The base app occupies ~448 MB, expanding to ~700 MB+ as your high-res artwork vault populates. You can place it on an external SSD or secondary game drive with zero C: drive bloat.
Logpile reads local manifest files already present on your machine—such as Steam's appmanifest_<appid>.acf, Epic Games' installation manifests, and GOG directories. You never enter account credentials or log into third-party servers.
Logpile is a 100% free, community-built open-source project. Code signing certificates cost hundreds of dollars per year from commercial certificate authorities. When installing, simply click "More info" and then "Run anyway" to launch. The entire codebase is open on GitHub for full community inspection.
When launching a game, Logpile delegates the execution directly to the Windows protocol handler and enters a quiescent idle state. It never consumes CPU cycles or GPU render pipelines during gameplay.
In Settings, you can optionally provide your personal SteamGridDB and IGDB API keys. Artwork queries happen only on demand and are cached permanently to your local logpile_data/artwork_database for seamless, permanent offline rendering.
